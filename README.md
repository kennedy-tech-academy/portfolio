# Deron's Portfolio

A portfolio website I am building during Kennedy Tech Academy’s six-week Web Development program.

## About the Project

This project introduces me, shares my interests, and showcases my work. I am building it step by step while learning how to structure, style, test, and publish a website.

## Project Goals

- Organize content with semantic HTML.
- Include About, Skills and Interests, Projects, and Contact sections.
- Create at least three project or content cards.
- Apply consistent colors, typography, and spacing.
- Build a layout that works on desktop and mobile screens.
- Add at least one JavaScript interaction.
- Support keyboard navigation and meaningful image descriptions.
- Save project history with Git and GitHub.

## Technologies

- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages for publishing

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
